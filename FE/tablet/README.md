# iPad Pro 12.9 현장관리자 화면

데스크톱과 다른 React 진입점과 메뉴를 사용하지만, 업무 데이터와 인증은 동일한 백엔드에 연결합니다.

- 가로 기준: 1366×1024, 세로 기준: 1024×1366 CSS px
- 실행: `pnpm dev:tablet` (5174 포트 고정)
- 빌드: `pnpm build:tablet`
- 미리보기: `pnpm preview:tablet`
- API 프록시: `/api` → `http://61.107.196.157` (데스크톱과 `vite.proxy.ts` 설정 공유)
- 결과물: `dist-tablet/`
- 실제 라우트와 제한: [INTEGRATION.md](../INTEGRATION.md)

로딩은 최초 진입 시 전체 화면, 메뉴 이동 시 본문 영역에 표시합니다. 최소 1초와 필수 데이터
조회 완료 조건은 데스크톱의 `PageEntry`를 공유하고, 태블릿은 서비스 보라색의 진행 막대를 사용합니다.
퍼센트는 실제 API 진행률이 아닌 대기 표시이며, 준비가 끝나면 100%를 0.2초 표시한 뒤 닫습니다.
검색·필터 변경에는 공통 로딩을 다시 표시하지 않습니다. 앱 내부에서 보고 상세로 이동할 때는
보고서 스켈레톤을 사용합니다.

홈·작업 지시(일정)·설비·수동 이상 보고를 서버 데이터로 표시합니다.
로그인·로그아웃·비밀번호 변경은 실제 계정에 적용됩니다. 회원가입은 관리자 사번 계정 발급 방식입니다.
캐릭터만 사용자별 브라우저에 저장하며, 채팅 및 자동 보고서 생성은 연결하지 않습니다.
