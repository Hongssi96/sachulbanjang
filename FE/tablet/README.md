# iPad Pro 12.9 현장관리자 화면

기존 데스크톱 App·라우터·세션·저장소와 연결하지 않는 독립 React 진입점입니다.
공통 디자인 스타일·로고·Modal 컴포넌트만 재사용합니다.

- 기준 크기: 가로 1366×1024, 세로 1024×1366 CSS px
- 실행: `pnpm dev:tablet` (5175 포트, 다른 포트로 자동 변경하지 않음)
- 타입 검사 및 빌드: `pnpm build:tablet`
- 빌드 미리보기: `pnpm preview:tablet`
- 주소: http://127.0.0.1:5175/
- 결과물: `dist-tablet/` (데스크톱 `dist/`와 별도)

기존 5175 미리보기 서버를 실행 중이면 해당 터미널에서 Ctrl+C로 종료한 뒤
`pnpm dev:tablet` 또는 `pnpm preview:tablet`을 실행합니다.
작업 지시(`/#/tasks`)·설비 현황(`/#/equipment`)·이상 보고(`/#/reports`)는 독립 태블릿 내부 화면입니다.
HashRouter를 사용하며 데스크톱 라우터나 서버에는 연결하지 않습니다.
작업 완료 처리, 설비 상세 확인, 이상 보고 작성·목록 조회는 예시 데이터로 동작합니다.
모든 데이터와 로그인 연장 표시는 시연용이며 새로고침 시 초기화됩니다.

## Mint & Plum 재디자인

- 첨부 대시보드의 흰색 사이드바·둥근 카드·여백을 현장 화면에 적용했습니다.
- 탭 참고 이미지의 선택된 탭이 떠오르는 형태를 품질 기간과 상태 필터에 적용했습니다.
- 흐름도 참고 이미지의 점선 캔버스·연결 노드를 현장 도우미에 적용했습니다.
- 팔레트: Deep Plum `#29263F`, Dusty Violet `#635B85`, Mint `#61E2A6`, Coral `#DD8296`, Warm Cloud `#F5F5F2`.
- 상태: 정상 Mint, 주의 `#F2BB69`, 고장 `#D95F70`, 미가동 `#A9AAB5`. 텍스트 상태를 함께 표시합니다.
- 재디자인 테마는 `TabletTheme.css`에만 있으며 데스크톱 엔트리에서는 불러오지 않습니다.
- 품질 추이와 AI 점검 수치는 예시입니다. 현장 도우미는 질문을 조합하는 시연 기능이며 AI 서버와 연동되지 않습니다.
