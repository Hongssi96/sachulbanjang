# 사출반장 · 프런트엔드

사출 공장 관리자를 위한 웹앱입니다. React + TypeScript + Vite, pnpm을 사용하며 react-router로 홈·실시간 공정·일정 관리 화면을 연결합니다.

## 실행

```bash
cd /c/Users/user/Desktop/Project_02/imleader/FE
pnpm install
pnpm dev
```

브라우저에서 터미널에 표시된 로컬 주소(기본 http://127.0.0.1:5173)를 여세요.

## 검증

```bash
pnpm lint
pnpm format:check
pnpm build
```

## 구현 범위

- 접을 수 있는 사이드바, 라이트·다크 모드, 알림 모달
- 공정 요약 4개, 조회 기간 전환이 가능한 생산량 차트
- 주요 설비 필터와 2D 배치 예시
- 현장 보고 목록·상세, 미처리 필터
- 월 이동·날짜별 일정 모달
- 인수인계 작성·확인 상태 관리 및 브라우저 저장
- 전용 대화·검색 화면에서 질문 입력과 예시 응답
- CSV 홈 요약 내려받기

홈, 실시간 공정, 일정 관리는 `/`, `/realtime`, `/schedule` 경로로 이동하며 정의되지 않은 주소는 페이지 없음 화면을 표시합니다. 재고·품질·생산/검사 이력·정밀기계검사·대화/검색 화면도 연결하며, 올라온 보고 메뉴는 준비 중 안내를 표시합니다. 서버, 인증, 실시간 데이터, 실제 AI 호출은 연결하지 않았습니다. 로그인 연장 버튼은 예시 상태만 변경하며 실제 세션을 연장하지 않습니다. 노트는 localStorage에 저장되어 같은 브라우저에서만 유지됩니다.

## 데이터 기준

일반 KPI, 설비 현황, 보고, 일정은 시연용 데이터입니다. 대시보드의 날짜·갱신 시각은 고정된 예시입니다. 품질 인사이트는 제공된 분석 참고 자료의 **과거 라벨 검사 기록**을 사용합니다. 전체 생산 불량률이나 현재 설비 고장으로 해석하면 안 됩니다. 오늘의 예시 KPI와 과거 인사이트의 집계 기간은 다릅니다.

## 디자인 및 구조

DESIGN.md의 Mint & Plum 팔레트, 공통 반경·간격, 로컬 Pretendard 폰트 및 제공된 로고를 사용합니다. 사이드바는 최신 Figma 화면의 구성과 브랜드를 참고하되 디자인 문서의 240px 공통 규격을 따릅니다. 홈 메뉴와 탐색 아이콘을 추가했습니다.

App.tsx에는 고정 셸(사이드바·상단바·공통 모달)과 라우트를 배치하고, pages/에는 홈·실시간 공정·일정·재고·품질·검사·대화 페이지를, components/에는 사이드바·상단바·모달·차트, constants/에는 예시 데이터, types/에는 공유 데이터 타입을 배치했습니다. 백엔드는 이번 범위에 포함되지 않습니다. 추후 Python·PostgreSQL API 연동 시 api/와 services/를 필요한 시점에 추가하세요.

모든 폰트 파일은 로컬에서 제공됩니다. Pretendard는 SIL Open Font License이며 라이선스는 public/fonts/OFL.txt에 있습니다. 로고는 사용자 제공 자산입니다.

## 실행 환경 참고

검증에 사용한 제한된 Windows 실행 환경에서는 esbuild가 사용자 홈 상위 디렉터리를 탐색할 때 접근이 거부되어 Vite 개발 서버의 의존성 최적화를 완료하지 못했습니다. 타입 검사·린트·프로덕션 빌드는 통과했으며, 실제 브라우저 동작은 빌드 미리보기에서 확인했습니다. 개발 서버에서 동일한 접근 오류가 발생하면 다음 명령으로 화면을 확인할 수 있습니다.

```bash
pnpm build
pnpm preview --port 5173
```

Vite 설정 로딩은 상위 경로 접근을 줄이기 위해 runner 모드를 사용합니다.

## 재고 관리

기존 홈과 사이드바의 디자인을 유지하면서 완제품 재고 페이지를 추가했습니다. 원자재는 기존 기획에 따라 후순위입니다.

- 전체 현재고·가용재고·출고 예약·부족 품목 요약
- 제품명·품목 코드 검색, 제품군·창고·부족 상태 필터, 가용재고 정렬
- URL 쿼리에 조회 조건을 보관하여 새로고침해도 유지
- 품목 상세, 안전재고 기준 변경, 입출고 등록 및 최근 이력
- 가용재고를 초과하는 출고와 잘못된 수량 입력 방지
- 조회 결과 CSV 내려받기, 빈 결과 복구, 다크 모드·반응형 레이아웃

재고는 시연용 데이터이며 변경사항은 현재 브라우저의 localStorage에 저장합니다. 가용재고는 현재고에서 출고 예약을 뺀 값입니다. 가용재고가 0이면 품절, 안전재고보다 적으면 부족으로 표시합니다. 최근 입출고 기록은 50건까지 보관합니다.

`src/pages/InventoryPage/`에 페이지, 입출고 폼, 상세 모달, 재고 계산·검증 로직과 스타일을 함께 배치했습니다. React Router는 URL 이동·뒤로 가기·직접 접속을 위해 추가했습니다. 홈과 공통 셸은 최신 dev 구현을 유지하고 신규 페이지를 같은 라우터에 연결했습니다.

정적 호스팅 시 `/inventory` 등의 직접 접속도 `index.html`로 연결하는 SPA fallback 설정이 필요합니다. Vite 개발 서버와 미리보기는 이를 지원합니다.

## 품질 리포트

품질 리포트는 `/quality-reports`에서 확인합니다. 기존 홈·사이드바·재고 관리 화면은 유지하고, 같은 디자인 규격으로 페이지를 추가했습니다.

- 기간 프리셋과 시작·종료일, 제품·설비 필터
- 검사 수량·검사 불량률·불량 수량·중점 확인 품목 요약
- 날짜별 추이, 불량 유형 분포, 집계 근거 확인
- 검사 배치 검색·결과 필터·페이지 이동·상세 모달
- 선택 조건의 일간·주간·월간 리포트 미리보기와 텍스트 저장, 표 결과 CSV 저장
- URL에 조회 조건 보관, 잘못된 날짜 및 빈 결과 처리

품질 데이터는 2026.11.04–11.17에 걸친 56개 검사 배치의 시연용 데이터입니다. 기본 최근 7일의 수량은 검사 2,480개·불량 60개이며 검사 불량률은 2.42%입니다. 날짜별 비율의 평균이 아니라 불량 수량 합계 / 검사 수량 합계로 계산합니다. 직전 기간은 같은 길이의 바로 앞 기간이며 같은 제품·설비 조건으로 비교합니다. 비교할 기록이 없으면 비율 변화를 표시하지 않습니다.

제품별 검사 불량률이 고정 점검 기준 3%를 초과하면 중점 확인 품목으로 표시합니다. 이 값은 전체 생산 불량률, 설비 고장 상태, AI 예측 또는 확정된 불량 원인을 의미하지 않습니다. 표의 검색·결과 필터는 상단 요약 및 리포트 집계에 영향을 주지 않으며 CSV에는 표의 필터 결과를 저장합니다.

Figma 도구의 호출 한도로 최신 시안은 재확인하지 못했습니다. 앞서 공유된 품질 화면 구성과 현재 로컬 홈 디자인을 기준으로 구현했습니다.

## 생산·검사 이력과 정밀기계검사

- `/records`: 날짜·제품·설비·담당자·검색어로 이력 조회, 생산/검사 탭 전환, CSV 다운로드
- `/records/:recordId`: 생산 배치와 표본 검사 결과 상세
- `/records/:recordId/precision-inspection`: 별도 정밀기계검사 화면, 측정 결과·점검 체크리스트
- 목록으로 돌아가면 검색 조건과 페이지 유지

검사 이력과 품질 리포트는 `src/services/inspectionData.ts`의 예시 데이터를 공유합니다. 생산 수량과 정밀기계검사 측정값·허용 범위는 시연용이며 실제 설비 기준이 아닙니다.

## 대화·검색

- `/chat`: 사이드바의 ‘과거 대화 이력 + 검색’에서 진입
- 새 대화, 대화 이력 검색, 브라우저 localStorage 저장·복원
- 검사 이력·보고·대화의 키워드 통합 검색과 관련 검사 상세 연결
- 질문 입력 시 예시 검사 데이터 기반 응답 제공

실제 AI API와 서버 검색은 연결하지 않았습니다. 예시 응답은 2026.11.11–11.17 검사 데이터를 기준으로 하며 실제 설비 상태나 불량 원인을 판단하지 않습니다. Figma chat/search 시안은 도구 조회 한도로 확인하지 못해 기존 홈 스타일을 기준으로 구성했습니다.

## 화면 사용성 개선

- 날짜는 YYYY.MM.DD, 시간은 HH:mm으로 표시하며 검사 이력과 품질 리포트는 공통 달력을 사용합니다.
- 대화는 Enter로 전송하고 Shift+Enter로 줄바꿈합니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 홈 하단 대화창을 제거하고 공통 사출반장 버튼을 전용 대화 화면에 연결했습니다.
- 품질 기간은 일간·주간·월간(시연 기준일 2026.11.17까지)으로 전환합니다.
- 재고 표는 필터 전환 시 높이를 유지하며 제품군 재고 툴팁은 마우스 및 키보드 포커스로 확인할 수 있습니다.
- 화면은 코드 분할로 불러오며 실제 로딩 중 스켈레톤을 표시합니다. 조회 전환과 대화 응답 모듈 로딩에도 진행 상태를 표시합니다. 시연 데이터에 인위적인 대기 시간을 넣지는 않습니다.
