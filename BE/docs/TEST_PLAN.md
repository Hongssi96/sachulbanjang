## 실행 계층

순수 계산·상태 전환은 단위 테스트, 권한·트랜잭션·RLS·제약·동시성은 별도 PostgreSQL 18 테스트 DB로 검증한다. SQLite로 PostgreSQL 동작을 대체 검증하지 않는다. 외부 AI 응답 대역은 외부 경계만 교체하고 서버의 SQL 검증·권한 로직은 실제 코드를 실행한다.

실제 AI 호출은 선택 실행으로 분리하며 응답 형식·품질·시간·모델 ID를 기록한다. 팀 승인 전송 범위가 정해지기 전 실제 민감한 업무 데이터로 시험하지 않는다. 대역 통과와 실제 연동 완료를 구분한다.

문서 단계에서는 상대 링크·요구사항 추적·금지된 범위 추가 여부를 검토한다. 앱 초기 구성 후 Ruff·mypy·pytest·마이그레이션 적용과 OpenAPI 계약 일치를 CI에서 확인한다. 아직 설정되지 않은 명령이나 Docker 앱 빌드를 실행했다고 기록하지 않는다.
